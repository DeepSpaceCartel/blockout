BLOCKOUT Admin

Blockout keeps only a first name, a last initial and an email domain for each account, so look people up by first name and school. Newest sign-ins first.

A teacher code makes one account a teacher: the person signs in on Blockout, then types the code (or opens its link). Each works once, for 7 days.

A school is matched by its students' email domain: only accounts from that domain can join its classes.
